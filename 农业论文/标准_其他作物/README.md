## 两点选材提示

1. **优先水肥一体化那一批**。系统当下最缺的是「带量的水肥处方」，而 `水肥一体化` 系列标准
   恰好是按生育期给灌溉量/施肥配方的形态（番茄那批就是靠 DB37/T 1849 的附录 A 制度表
   把水肥处方从「给不出」变成「给得出」的）。上表里标了「水肥一体化」的 7 份是首选。
2. **甜玉米/复种/盐碱地这类特殊茬口要单独判断**，不要把它们的用量当通用值
   （`DB4107/T 414`、`DB1302/T 479`、`DB4413/T 51`、`DB15/T 3329` 属此类）。
