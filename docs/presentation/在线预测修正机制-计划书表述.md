# 基于机理模型与数据同化的在线生长预测修正

供计划书、PPT 和答辩直接使用。主线为“模拟观测数据持续到达，驱动预测在线修正”；M3 三年数据作为参数标定与验证来源介绍。

## 一、计划书正文

针对设施农业生产中环境变化持续发生、生长观测相对稀疏、固定参数模型易产生累计偏差的问题，项目构建机理模型与观测数据融合的在线生长预测机制。系统以有效积温驱动番茄节间出现与伸长，形成连续生长预测；同时模拟环境数据持续接入和株高观测逐次到达，通过扩展卡尔曼滤波将新增观测信息融入生长状态，形成“机理预测—观测接入—状态同化—递推预测”的持续更新过程。

修正过程中，系统综合模型预测不确定性与观测噪声估计，动态确定观测对当前状态的影响程度。没有新生长测量时，模型继续推演并传播不确定性；观测到达后，系统根据预测与观测之间的偏差更新有效热龄状态及其不确定性，并从新的状态继续预测。对于含估计值的环境输入，当前实现提高过程噪声，体现数据可信度差异。每次更新保留观测前预测、到达观测、更新后状态和观测权重，使修正过程可解释、可追溯。

现阶段使用 Horti-M3 公开历史数据按时间顺序回放，模拟在线采集与异步观测接入；后续可沿用该预测与更新流程接入现场环境传感器和人工表型测量。基础生长参数通过历史批次预先标定，在线阶段保持固定；系统随新增观测递推更新生长状态。评价采用观测到达前的预测误差检验预测能力，并单独报告吸收本次观测后的拟合偏差。当前验证对象为番茄株高，后续扩展至其他生长指标时，需要重新明确观测关系、噪声假设并开展验证。

## 二、技术特色表述

**机理模型与观测信息融合。** 利用温度驱动的生长机制建立连续预测，再通过非线性状态估计吸收新增表型观测，将生长解释与数据反馈结合。

**适应稀疏观测的递推更新。** 环境记录按半小时推进，株高在实际测量日期到达；系统在两次生长测量之间持续预测，在新测量到达时更新状态，保留不同数据频率。

**以不确定性确定修正幅度。** 卡尔曼增益随状态方差和观测噪声变化，观测权重由当前估计计算。环境补值提高过程噪声，体现输入质量对估计可信度的影响。

**预测与修正全过程留痕。** 记录“预测值—观测值—修正值”、来源及更新权重，区分参数标定、观测前预测评价和更新后拟合效果。

创新贡献建议定位于上述方法在农业场景中的集成、观测流组织和可追溯验证设计。当前实现采用已有的 Logistic 生长函数和扩展卡尔曼滤波。

## 三、PPT 一页版

**标题：机理模型与观测数据融合的在线预测修正**

**一句话：让生长预测随新增观测持续更新。**

**流程：环境输入 → 机理预测 → 新观测到达 → 不确定性加权同化 → 状态更新 → 下一阶段预测。**

- 连续预测：有效积温驱动番茄节间生长。
- 动态修正：扩展卡尔曼滤波递推更新有效热龄状态。
- 数据质量：估计输入提高过程噪声，更新保留来源与权重。
- 可验证：分别展示观测前预测误差与更新后拟合偏差。

页脚：现阶段采用 M3 历史观测顺序回放模拟在线接入，设备处置属于仿真。

## 四、答辩口述版

“我们的生长预测会随新增观测持续修正。环境数据进入模型后，模型先预测；新株高测量到达时，再根据预测和观测的不确定性更新生长状态，之后从修正后的状态继续推演。目前我们用公开 M3 数据按时间回放，模拟这个在线过程。后续接入现场传感器和人工测量后，可以沿用相同的预测与更新流程。”

## 五、评委追问时的回答

**为什么用三年数据？** 历史年份用于基础参数标定，保留年份用于检验跨年份预测表现和模拟在线观测接入。年份说明数据来源与评价设计，项目展示重点是数据到达后的递推更新机制。

**修正的是哪里？** 当前主要修正有效热龄这一生长状态，由状态变化带动株高预测和后续轨迹更新；在线阶段的基础生长参数保持固定。

**是不是直接让曲线贴合测量？** 系统按不确定性吸收观测，修正后的状态用于后续预测。有效性应看下一次观测到达前的误差，更新后的贴合程度另行报告。

**会不会一直变准？** 更新引入了新信息，但效果取决于模型假设和观测质量，因此保留误差评价和来源记录，逐批验证。

**能否修正产量和病害风险？** 当前已实现株高状态同化。风险模块另按环境阈值和持续暴露进行提示；产量、品质及病害状态同化需要补充可靠观测和相应模型，作为后续扩展。
