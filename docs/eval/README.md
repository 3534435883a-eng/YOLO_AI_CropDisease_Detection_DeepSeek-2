# 项目评估协议

本目录用于区分三类证据：检索排序质量、智能体回答约束、以及番茄数字孪生的候选前瞻仿真。三类结果不能合并成一个“智能体准确率”。

## 评测集

- `developer_holdout.jsonl` 是开发者编写、与生产知识库索引构建过程分开的保留集。每条记录只包含问题、作物、期望主题和是否应拒答，不复制知识库原文作为答案。
- 在 `YOLO_AI_CropDisease_Detection_SpringBoot` 目录运行 `mvn -Dtest=DeveloperHoldoutEvalTest test` 可执行 BM25-only 保留集检查。测试会逐题打印检索层误接纳；它不调用 LLM，也不代表完整智能体最终答复。
- 评测集变更必须追加版本号并记录变更原因；调参和提示词修改只能使用训练/开发集，不能根据保留集逐题调参。
- 当前保留集没有农技专家双人标注，因此结果只能称为“开发者保留集结果”，不能称为独立农艺验证。

## 指标

1. 检索：Top-1/Top-3 主题命中率、无依据问题拒答率、别名问题误拒率。报告检索模式（BM25、向量或融合）和语料版本。
2. 回答：引用编号有效率、无依据问题的拒答率、设备越权声明拦截率。引用编号检查只能验证编号存在且属于当前证据列表，不能证明文字在语义上被证据充分支持。
3. 仿真：各策略的产量、风险暴露、资源消耗和成本。`P3_AGENT` 当前实现是候选动作的前瞻仿真，不调用 LLM/RAG；报告中应使用“P3 候选前瞻仿真”这一名称。

## 报告最低要求

- 给出样本数、语料/模型/代码版本、运行时间和失败样本列表。
- 只报告实际运行得到的数值；向量服务不可达时明确标注 BM25-only 降级。
- 不把论文中的碳捕集数据、AutoML 指标或收益数字迁移为本项目农业结论。

## 当前发现

首次运行 4 条开发者保留集时，检索层对 2 条应拒答问题均给出了非低分结果（2/2 误接纳）。其中潜叶虫问题还会经过视觉映射工具独立判断；不能把检索层误接纳直接等同为最终答复错误。扩大保留集并请农技人员复核标注后，再评估检索阈值和跨主题拦截规则。
