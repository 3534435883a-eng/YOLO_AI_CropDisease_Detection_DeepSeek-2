# M3 数据流与番茄模型在线纠偏设计

## 2026-10-02批准与范围补充

用户已认可在线纠偏，并追加风险预警、多因素计算。按后续“可以”执行：同一时序流同时推进节间株高、光温CO₂驱动的RUE生长参考、实时环境/持续暴露风险。温度/湿度计算VPD，预警包括高温、低温、高湿、VPD偏离、估计输入与株高观测偏离；预警返回当前数值、持续时间、依据及检查建议，不输出未经验证的发病概率或自动控制实物。

LAI已见0.6–2.27但地面面积口径未确认；LDW原值0.05–0.09不能直接换算为模型g/m²。因此本轮LAI/LDW作为到达后的原始参考展示，暂不直接同化；模型初始LAI与器官质量仍明确为假设。M3土壤VWC保留原读数，水分胁迫保持中性假设。生长参考使用已有advanceCalibrated修正后的PPFD能量换算；株高继续采用冻结的节间机制，二者不虚构共同生理校准。

高温29°C、冷14°C、严重热34°C及VPD高2.0/低0.3kPa为可追溯工程阈值；高湿85%依据番茄叶霉病环境资料，但缺少叶面湿润/病原资料，只显示环境条件提示。连续暴露计时按数据时间而非演示墙钟。默认一秒推进一天，保留经过的全部预警事件。切换到大棚时保留同一运行，暂停数据消费；其它离开场景暂停计时，后端30分钟无活动后清理。

## 用户目标

演示时将M3历史数据按时间顺序作为传感器输入，模型随环境预测，株高观测到达时在线修正当前生长状态，并把修正持续带入之后的预测和三维大棚。界面明确标注“M3历史数据实时回放”，区分数据原时间与本次接收时间。

## 方案选择

1. **推荐：冻结历史参数，在线更新生长状态。** 保留2023/2024拟合的节间参数，使用一维扩展卡尔曼滤波（EKF）修正每株的有效热年龄。适合当前非线性节间模型和稀疏株高观测，计算量小，更新前后可解释。
2. **备选：在线重拟合参数。** 随观测增加反复拟合节间间隔与长度。能研究机制适应，但少量观测下参数相关且易漂移，展示和评价都更复杂；本轮推荐先完成状态更新。
3. **备选：观测到达直接重设株高。** 展示简单，但忽略测量误差、没有模型与观测的权重计算，不适合作为本项目首选修正算法。

## 一条运行流程

开始接入 → 按时序读取M3环境 → 模型预测 → 株高观测到达 → EKF修正状态 → 从修正状态继续预测。

- 默认2025 CK/广辉201作为展示季；可重开2023/2024季，但不会把跨年拼成同一植株。2023/2024与历史参数拟合重叠，不能称独立验证。
- 复用半小时环境驱动与统一补值来源。原始测量日仍按12:00对齐假设，不将每天的插值株高伪称新实测。
- 首日株高只初始化。其后只处理当前游标之前及当前到达的观测，不查看未来株高，不反向修改已经发布的预测。
- 演示提供半小时/6小时/1天的推进速度，默认每秒推进1天；每次批量推进内部仍逐个半小时时段计算，所有经过的纠偏事件都保留。
- 播放、暂停、单步、重置统一控制数据游标。暂停后停止消费数据。选择年份重建运行；曲线只绘制已到达部分。

## 算法

每株保存有效热年龄a和方差P；冻结参数p、L、k、m、基温来自现有校准结果。观测函数h(a)为已有ThermalInternodeHeightModel的株高总和。

1. 环境到达：a_prior = a_previous + max(0,T−10) × dtDays；P_prior = P_previous + Q。
2. 尚无株高观测：发布h(a_prior)，继续推进，不造测量。
3. 株高z到达：计算D=dh/da，S=D²P_prior+R，K=P_prior D/S，a_post=a_prior+K(z−h(a_prior))。
4. 方差使用Joseph形式：P_post=(1−KD)²P_prior+K²R；发布h(a_post)，下一时段从a_post继续。
5. 每次保存预测值、观测值、更新值、偏差、状态变化、增益、方差、观测来源和时间。状态修正可上调或下调，不为曲线好看强行单调。

初始与测量不确定度默认标准差5cm（R=25cm²）；过程不确定度默认每一天方差增长4cm²，以当前株高导数换算到热年龄方差。估计环境时过程方差乘4。以上为显式工程假设，不用2025后续误差优化，也不宣称置信区间已验证。初态P以R/D²换算；导数过小、非有限值或协方差无效时停止该更新并报告原因，不悄悄改用观测覆盖模型。

模型推进仍依据收到的环境和当前状态，本轮不在线重拟合节间参数，不把株高状态更新扩展宣称为果实、叶面积或设备控制校准。

## 后端边界

- 新建独立在线运行服务与滤波内核，不改变已保存的跨年校准版本、原始观测、AgentRun与默认规则模型。
- POST /m3/live/start：year，返回runId、冻结参数版本、首日状态、cursor和来源说明；不返回未来观测。
- POST /m3/live/{runId}/step：expectedCursor与stepCount（1/12/48），顺序消费数据，返回新增帧、事件、当前状态与已到达测量的统计。
- GET /m3/live/{runId}：当前已发布状态；DELETE /m3/live/{runId}：释放运行。
- 每个运行加锁，游标不匹配拒绝推进并返回可恢复状态，避免重复请求吞掉数据。每个浏览器最多一个活动请求；切换年份和离开页面释放运行与计时器。
- 内存运行30分钟无活动后释放；服务重启或运行失效明确提示重新开始，不继续展示旧快照作为最新状态。结果导出包含已消费帧、事件、源文件及算法参数，不包含尚未到达数据。

## 界面

在现有模型校准工作区增加实时回放操作区，作为一条主展示流程：

- 两条线：“固定参数模拟”（不使用后续株高）与“实时纠偏模拟”；散点为截至当前游标已收到的M3原测。
- 显示当前数据时间、接收状态、累计纠偏次数和最近事件：“预测x → 观测z → 更新y”。
- 有测量到达时强调事件与更新位移，其他时段显示“模型预测，等待株高观测”。
- 冻结参数的历史评价放在详情中，清楚区分参数校准与在线状态更新。
- 大棚跟随在线更新后的当前株高，接入同一runId；不再播放预先算好的完整纠偏轨迹。保留设备和叶果示意说明。
- 播放结束可导出本次过程；错误时暂停并显示原因，不补造结果。

## 评价口径

主要统计每次新测量到达之前的预测残差，与固定参数、不在线纠偏的节间模型比较；首日排除。该统计反映使用过去观测后，对下一次观测的预测能力。

当次更新之后的残差作为“更新后拟合偏差”单列，不能当作独立预测精度。在线2025已使用到达的株高，不能沿用旧结果“后续株高全部不参与”的说明。完整历史保留评价结果独立保留。
