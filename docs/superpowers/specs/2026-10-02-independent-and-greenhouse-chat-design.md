# 普通问答与关联大棚并存

用户澄清：决策助手继续关联大棚，当前样式可以；同时需要原来独立的普通问答。此为已批准集成方案的范围修正，直接实施，保持暖白农业绿及现有回答/来源界面。

- 同一助手页面增加“普通问答”和“关联大棚”入口。直接进入助手默认普通问答；从大棚携带liveRun进入默认关联大棚。
- 两个入口分别保存会话ID、消息、草稿、作物和图像附带选择，避免模型历史互相混入；切换不清空另一侧的状态。生成期间暂不切换。
- 普通问答使用多作物选择、知识检索、病害解释及通用大模型回答；请求不包含M3运行ID，工具目录不暴露无关联的模拟状态/执行工具。
- 关联大棚沿用现有状态卡、示例问题、实时快照和受约束动作；只读取已有运行。切换入口和打开大棚均不创建、重置或推进运行。
- 当前关联过期只影响关联入口，普通问答仍可用。关联状态卡保留准确错误信息。
- 页面具名与现有keep-alive路由保持一致，普通与关联的前端会话在页面往返时保留；本轮不增加持久会话恢复或跨浏览器同步。
- 沿用既有停止/重新回答；重试保持原提问作物且不执行新动作。
- 不新增或运行自动测试；构建确认可编译。后端打包会使开发服务重载、清空既有内存运行，交付时如实说明。

自审：普通会话与大棚会话隔离；保留既有能力及界面；不修改环境响应模型或设备方案。
