# 模拟大棚交互与动画增强

## 目标与现状

增强桌面数字孪生的可操作性，让设备位置、运行状态及动画之间的关系更容易理解。沿用现有 Three.js、Vue、M3 番茄场景及配色。

现有场景已经提供自由飞行、环绕、设备目录定位与点击检查；已有风机旋转、通风窗开合、遮阳幕滑动、滴灌水滴、CO₂ 补给示意、补光、冠层摆动及日级生长插值。因此新增工作以交互反馈和运行过程说明为主。

## 推荐方案：交互与运行联动

### 设备探索

- 环绕模式下，鼠标悬停可检查设备显示轻量边框和名称；移出画布后清除提示。
- 点击选中设备保留选中边框及详情；详情提供“靠近查看”按钮，主动点击后镜头平滑接近。避免点击查看就强制拉动镜头。
- 设备目录选择与画布选择同步；详情关闭或点击空白区域清除选中状态。
- 拖动相机结束不触发设备选择；自由漫游锁定指针时沿用中心准星选择，取消屏幕位置悬停。
- 传感器显示当前来源、读数及单位；无快照或缺失值显示未记录。

### 运行动画

- 保留既有开合、风机、水滴和补光动画，新增可切换的“运行流向”图层：HAF 环流、端墙排风、灌溉管路和加热热流各自用轻量定向线段/粒子表达。
- 流向图层只在相应设备当前状态为运行时出现，停止后平滑消失；气流和热流是示意，不能显示为流体求解或测量结果。
- 历史快照和 API 日级数据由现有数据状态驱动；本地演示开关只在离线示例模式生效，明确显示“仅场景演示”。
- 动画增速不改变仿真步长、资源账本、模型数值或历史记录；不新增远程设备命令。

### 可控巡览

- 增加设备巡览：供水区、作物区、感知节点、通风设备之间平滑移动，并显示站点名称及序号。
- 提供巡览/暂停/继续/结束；用户拖动、切换自由漫游或主动定位设备时结束巡览，立即交还相机控制。
- 页面隐藏时暂停巡览，恢复可见后仍保持暂停，避免未观看时自动跨站。
- 巡览不自动开启设备或启动后端运行，不加入“开始演示”“查看答辩路线”等此前明确移除的按钮。

## 可选方案

1. 展示动画为主：重点做巡览、现有昼夜循环的可调时钟与现有日级生长回放入口，较少新增设备反馈。
2. 交互和展示动画都做：推荐方案上再补昼夜时钟滑杆、日级回放快捷入口；半小时历史快照保持原始时刻和固定示意植株，不借日级动画伪装实际长势。

用户已选择“交互和展示动画都做”，实施推荐方案及展示快捷控制。沿用已确认界面，不额外增加审批流程。

## 用户追加：整个大棚界面

用户同时要求完善整个大棚界面。沿用已批准农业平台暖纸色与橄榄绿，将顶部模式/数据切换、左侧探索、右侧设备详情和底部视角工具按操作频率分组。探索面板分“设备与巡览”“生长与光照”两个标签；探索面板与完整数据HUD互斥，避免遮挡叠加。设备目录提供搜索及唯一跨号，保留半小时仿真、日级评测、画质、资源与经济数据功能；增加全屏入口。默认日级光照为12:00展示时钟，明确仅改变渲染光照，不修改日级指标。

本地示例模式下，详情提供对应设备的演示启停和复位；API评测及保存快照不允许本地演示覆盖。CO₂与换气互锁仍在场景状态中执行。半小时传感器缺失快照值时显示“未记录”，不将回退展示值称为保存的读数。

## 实现边界

- 新增交互选择和流向效果分别放入独立场景模块，scene.ts 管理生命周期及状态接入；index.vue 只管理控制与详情展示。
- 复用现有 equipment.entries、稳定 deviceCode、focusEquipment、当前快照适配与 requestAnimationFrame，不引入额外动画框架或新3D资产。
- 流向效果使用固定数量几何/粒子并复用缓冲区；射线悬停只在指针移动后节流更新，不每帧更新 Vue 状态。
- 手动画质档位有效；低画质减少流向粒子，设备、选择与详情功能保留。
- 页面卸载清理指针监听、巡览状态、几何和材质；选中标记不修改设备原材质，不遗留高亮。
- M3 原始数据仍在下载；本轮不导入实测、拟合参数或宣称已校准。

## 验收方式

沿用既有不新增或运行实现测试的约束。实施后做前端生产构建、静态检查及浏览器展示核对，记录实际看到的效果；不据此宣称完成性能基准或模拟精度验证。

## 自审

明确区分已有动画与新增反馈；API/历史状态与本地演示保持分离；巡览可中断且不控制设备；推荐方案与展示方案边界明确。文档无待补字段，范围已由用户确认。
