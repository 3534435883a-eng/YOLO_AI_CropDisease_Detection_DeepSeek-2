# 农业智能体平台桌面端改版设计

## 目标

为项目演示与答辩重整农业平台的全站界面和功能导航。采用“禾序·田间档案台”的编辑式田间记录风格，让观众能从一次病叶观察，顺着证据与方案走到温室仿真和结果复盘。

改版保留现有业务能力、接口和数据含义，重点调整桌面端视觉语言、页面层级、入口组织与演示信息的可读性。当前温室模型是规则仿真；界面必须持续区分仿真、实测、离线样例和视觉识别信号，不改变数据来源或夸大模型结论。

## 视觉方向

- **主题：** 温室里的田间档案与作物观察记录，传达农业现场、研究记录与可追溯决策。
- **颜色：** 暖纸白作为主画布，深木棕用于导航，陶土红强调当前步骤与主要操作，低饱和橄榄绿用于有依据、完成或安全状态；正文使用深石墨色。
- **字体：** 中文衬线标题用于页面主标题和少量章节标题，清晰的无衬线字体用于导航、表单、数值和说明。英文只作为小型栏目索引，不承担主要信息。
- **质感：** 细线分区、轻微纸张层次和少量真实作物图像。避免高饱和荧光色、发光渐变、厚重阴影、密集小卡片和装饰性大屏图表。
- **桌面优先：** 以 1440×900 展示为设计基准。宽屏使用完整侧栏与内容网格；中等桌面宽度可压缩侧栏并重排网格；手机尺寸只需保持基本可操作，不把桌面工作流缩成手机卡片布局。

## 全站框架与导航

以稳定的左侧工作区导航、顶部场景与来源状态、右侧主内容构成桌面应用框架。侧栏按用户任务分组，当前所在步骤清晰可见；同一操作相关的识别记录放在病害识别分组下，知识与系统管理退到次级位置。

建议导航顺序：

1. **工作台**：当前运行、主流程、最近观察、待关注事项与结果来源提示。
2. **病害识别**：图片、视频、摄像识别，以及对应识别记录。
3. **决策与规划**：知识检索型决策助手、独立农事规划推演。
4. **温室推演**：智能体指挥中心、环境详情、温室档案与数字孪生。
5. **知识与数据**：病害知识库、视觉—知识覆盖；删除“数据大屏”入口及对应页面。
6. **系统管理**：农资采购、库存、用户与个人设置。

“决策助手”和“农事规划推演”保持为两条并列通道：前者回答必须基于可引用知识依据的问题，后者根据人工输入、文本或 CSV 农情生成方案并允许核对解析结果。导航、页面标题和来源标记都要让这两种可信度来源易于区分。

删除 `/dataView` 的可见入口、路由和专属页面实现；清理只被该页使用的数据大屏资源。若仓库审查发现该页资源被其他功能复用，应保留被复用资源。既有其他业务页面与 API 路径不因菜单重新分组而改变。

## 工作台

工作台是进入项目后的场景首页，不是第二个数据大屏。使用一个明确的温室场景抬头、横向四步主流程和少量有来源的数据摘要组织页面：

1. **观察：** 图片、视频或摄像头识别，查看观察信号和识别记录。
2. **研判：** 在决策助手核对疾病知识条目、引用来源和适用边界。
3. **方案：** 使用独立农事规划通道，展示人工输入、文本解析或 CSV 上传及待确认步骤。
4. **复盘：** 创建或打开规则仿真，查看运行快照、虚拟设备、数字孪生回放与报告。

工作台保留现有“当前运行、温室状态、待关注事项、最近识别信号”的数据能力，但按主流程重新编排；没有活动运行或服务不可用时显示明确空状态，不显示伪造的指标。首页主标题区域不放“查看答辩路线”或“开始演示”按钮。创建运行、开始、暂停等业务操作仍在相应的仿真工作区完成。

每项数值或状态就近标注来源，例如“规则仿真”“知识库引用”“识别样本”“实测”或“离线示例”。仿真场景名称固定说明“8 号温室 · 番茄”；任何示例温湿度、设备量或风险值不得伪装成传感器实测。

## 主要页面布局

- **病害识别：** 将输入方式、样本预览、识别动作与候选结果放在同一主工作区；风险/知识解释作为下一步，不把视觉模型候选直接表现为确诊。
- **决策助手：** 保持对话、检索来源、知识条目和引用证据的清晰对应，证据不足时明确提示。
- **农事规划推演：** 使用输入/导入、解析草稿核对、方案结果与基线对比的连续步骤；不与检索型助手合并。
- **智能体指挥中心：** 将仿真配置、运行控制、运行摘要、告警、设备动作和资源流水按操作顺序编排；15 分钟规则步长、开始/暂停/单步/回放/重置等能力保留。
- **数字孪生温室：** 三维场景为主画面，侧边信息面板可收展；时间轴、视角、设备目录和指标图表分层放置。明确区分保存的 15 分钟快照、日级离线评测和本地模型交互。
- **知识库与历史记录：** 维持熟悉的搜索、筛选、表格和分页效率，只更新标题、间距、颜色、详情层级和空状态，不牺牲数据密度与操作功能。
- **系统管理：** 继续使用适合表格和表单的紧凑排版，视觉基调沿用全站但不过度编辑化。

## 交互与状态

- 左侧导航和当前页面标题使用同一套路由分组，直接 URL 访问已有业务页面仍可用。
- 主流程步骤链接到已存在的对应页面；不为这次改版新建重复入口或虚构业务能力。
- 加载中、无数据、服务不可用、低/高风险和操作成功/失败需要分别有清楚状态；颜色之外再配文字或图标，不只靠颜色表达。
- 危险操作继续使用现有确认交互；仿真重置要说明会清除本次虚拟运行历史。
- 图片、报告、记录、对比与三维回放继续使用已有 API 和数据契约。

## 约束与验收标准

- 不改后端计算逻辑、数据库结构、API 契约、权限或业务语义。
- 页面主要目标视口为 1440×900；常见桌面宽度下侧栏、表格、三维视口和主流程可读、可操作，无横向溢出遮住核心操作。
- 所有原有主要业务入口仍能从新的导航或工作流到达，菜单标题不重复且分组能解释先后关系。
- `/dataView` 不再出现在菜单中，也不再加载旧数据大屏页面。
- 工作台不含“查看答辩路线”和“开始演示”按钮；仿真所需业务操作仍在指挥中心保留。
- 用户可沿“识别 → 知识核对/规划 → 仿真 → 复盘”完成演示；两种 AI 通道从入口到结果都能区分。
- 所有样例、规则仿真、视觉候选和真实观测均如实标明，页面不得把虚拟状态描述成真实设备控制或实测结果。
- 表单、上传、记录筛选、图表和数字孪生交互继续可用，改版只改变呈现和导航组织。

## 暂不包含

- 新增农业模型、遥测硬件接入或执行器控制。
- 更改病害分类、仿真参数、策略规则、模型可信度或评测口径。
- 增加独立的答辩导览流程、演示模式或第二套大屏。
- 为视觉效果删除识别记录、知识证据、筛选项、仿真控制或来源声明。
