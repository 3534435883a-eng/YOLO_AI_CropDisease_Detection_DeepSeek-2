# Horti-M3 观测导入与双轨校准方案

## 目标

将自主番茄模型的预测与公开 M3 观测置于共同条件下比较，以实际误差支持参数修正。保留原模型，记录修正后的模型版本；未来复用同一观测接口接实时传感器。

## 数据流

原始文件 → 来源与字段核对 → 观测目录 → 同批环境输入 → 自主作物模型 → 与 M3 生长观测对齐 → 校准 → 独立保留数据验证。

## 对照口径

- 固定同一季、品种、处理与植株/面积口径。840 株和252 m²是全试验规模，不能默认是 CK 的观测样本量。
- 第一阶段比较具有兼容单位/测量定义的株高、LAI和干重/产量；尚未确认的指标不计算误差。
- 使用 M3 温湿度/CO₂等环境观测驱动作物模型时，这些变量是输入，生长输出才是待验证量。
- lux保留原值，PPFD转换需要显式方法和不确定性；初始作物状态依实际观测或明确假设建立。
- 温室环境动态响应另需室外条件与控制时序。文件没有记录时保留未校准标签。

## 模型版本与修正

原模型和修正模型分别保存参数、输入来源和运行版本；界面展示 M3观测、原模型、修正模型三条轨迹。校准使用一段数据，效果使用另一段数据或另一季评估。误差含样本数、MAE、RMSE与偏差。没有保留验证结果时不能称为验证通过。

## 存储与导入

原始文件放外部数据目录并保留文件哈希；解析记录保留文件、工作表、原列名、时间戳与植株编号。不把公共观测写入既有 AgentRun 历史。实际解析器在取得真实文件并核对列名后确定。

## 实时接入

复用时间戳、指标、单位、来源和质量标签的观测契约。实时数据用于当前状态校正；积累足够观测后再开展参数校准与版本发布。
