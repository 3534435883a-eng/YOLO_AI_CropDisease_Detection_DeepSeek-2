# 决策助手与温室推演参考审查

日期：2026-10-02。状态：参考审查后已按批准设计实施；交付能力、实际流程及限制见[实施结果](2026-10-02-greenhouse-ai-integration-results.md)。以下问题与480/35索引数是改进前的审查基线，当前索引为495个块、495个向量、41个来源。

## 一、当前项目真正需要改什么

本次审查发现，DeepSeek服务已经接入，问题集中在编排和上下文连接：

- `AgentOrchestrator` 将有无知识库词条命中作为通用回答的前提；检索降级时会直接拒答。有价值的一般问题因此可能得不到回答。
- 通用回答必须带固定的经验声明，普通回答又固定要求结论、依据、风险，表达容易模板化。通用回答分支未统一写入会话历史，追问也可能丢失上下文。
- `AgentChatRequest` 虽有旧版数字 `runId`，控制器没有将它传给编排器。当前M3运行使用字符串UUID，聊天前端也没有传入这条运行；助手无法可靠读取正在展示的大棚。
- 当前M3三维展示的设备状态全为关闭。已有设备动画和环境响应计算可复用，需要连接事件、决策、设备和后续反馈。
- 聊天正文目前主要以段落和引用编号显示；原始工具步骤占据正文前方，缺少列表、强调、表格与动作结果的清晰呈现。

运行中 `/ai/knowledge/status` 的只读结果为480个块、480个向量、35个来源，向量检索与嵌入服务可用，模型为BAAI/bge-small-zh-v1.5。这是本次查询的索引状态，不是永久保证。库中已有栽培、水肥、环境和用户论文摘要；需要同时修复检索使用方式和补齐具体缺口。

## 四、补库来源与优先缺口

进一步核对清单：DB21/T 3417已有通风排湿与缩短结露时间，DB41/T 1350已有越冬温湿、连阴雨雪和CO₂条目，DB61/T 1422已有灾害天气管理。新增资料重点补暴雨/强风的设备约束、湿帘与高湿关系和事件处理反馈；已有主题应增强检索与条件匹配，不重复当作空白补库。

1. **异常天气处置**：参考[农业农村部2024冬季蔬菜生产技术指导意见](https://www.moa.gov.cn/gk/nszd_1/nszd_2/202411/t20241113_6466168.htm)及[福建省农业农村厅转载的2023强降温大风降雨指导意见](http://nynct.fujian.gov.cn/ztzl/kpxj/zrzhl/202304/t20230423_6153806.htm)。整理温室加固、通风约束、保温、外部排水和阴雨水分管理，保留地域、棚型、季节与发布日期。文中的当年天气预报不作为模拟阈值。
2. **湿度、结露和降温耦合**：参考[Tennessee Extension W017](https://utia.tennessee.edu/publications/wp-content/uploads/sites/269/2023/10/W017.pdf)中的温湿调节机制。高湿下蒸发降温效果减弱，冷湿天气需要兼顾排湿和保温。旧版推广资料的数值区间不能覆盖本地标准；资料有差异时说明条件。
3. **补光与CO₂联动**：先完善已有补光、覆盖CO₂论文的检索主题及条件字段；模型未知光照换算继续标为假设。弱光时不能仅靠提升CO₂承诺恢复生长。
4. **模型解释与反馈**：将观测同化、控制反馈和环境暴露的论文方法整理为研究摘要，明确“环境风险提示”“模型输出”“观测记录”的区别。
5. **缺少输入时的回答**：果实硬度/饱满度、叶面湿润、真实室外风速、病原与设备功率没有测量时，说清已知信息及需要补充的测量；不能用静态论文填出当前棚的实测值。

新增内容采用独立摘要与可追踪出处，避免全文复制与重复灌入现有标准。知识清单须注册到CitedKnowledgeReader，按来源分组入库、生成向量、重新加载索引，并显示实际来源与条目状态；只放PDF进目录不算完成检索接入。当前六篇用户论文已在摘要清单中，本轮应补条件和可检索主题，避免重复建来源。

## 五、统一方案

M3按时到达 → 生长预测与株高更新 → 随机天气影响模拟环境 → 环境风险提示 → AI读取同一运行并按需查资料 → 校验并执行仿真设备动作 → 下一时段计算温湿光变化 → 观察效果 → 调整或报告未解决。

普通聊天使用同一助手和运行上下文：一般解释可自然回答；涉及当前大棚先读取实时快照；具体阈值、研究结论和处方需要相应依据。正文先回应用户关心的问题，复杂问题再展开过程。来源和执行记录以元数据呈现，不要求每个问题套同样标题。

M3原始记录保持来源；虚拟事件、设备响应和未干预对照为模型推演。参考论文增加机制依据，不能替代本项目的参数校准与效果评价。具体设计见[实施前设计](../superpowers/specs/2026-10-02-greenhouse-events-ai-design.md)。
