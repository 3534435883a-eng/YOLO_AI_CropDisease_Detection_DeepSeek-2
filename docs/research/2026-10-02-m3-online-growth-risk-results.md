# M3在线生长纠偏与环境预警

## 已实现的流程

开始接入 → 半小时环境记录推动预测 → 真实测量日期株高到达 → EKF更新有效热年龄 → 从新状态继续预测。默认演示每秒推进一天，内部仍处理48个半小时时段；没有测量时不造株高观测。

模型校准页新增在线工作区，曲线仅画已消费数据；固定参数模型与实时纠偏模型共用冻结节间参数和温度输入。散点是已到达M3测量。大棚接收同一个runId的当前状态，切换页面暂停播放、保留运行，进入大棚后可继续。

## 因素如何使用

| 数据 | 当前计算 |
| --- | --- |
| 温度、时间 | 积温推进节间株高与物候参考 |
| 株高 | 首日初始化；之后每株EKF更新有效热年龄 |
| 光照、CO₂ | 修正能量换算的RUE参考，冠层截获及干物质积累 |
| 温度、湿度 | 派生空气VPD/露点，环境与持续暴露预警 |
| 土壤VWC | 读取原值；单位关系未校准，模型水分胁迫暂保持中性 |
| LAI、LDW | 只展示已到达原值；仪器/地面面积单位未对齐，不同化 |
| 果实、风 | 没有果实饱满度/风速实测接入；叶果设备保持示意 |

株高状态纠偏不自动改变RUE生理阶段、器官干重或产量。当前实现提供并列的形态、干物质参考与风险计算，尚未完成所有器官的生理耦合校准。

## 纠偏计算

每株状态a为有效热年龄，观测函数h(a)是既有节间长度求和。冻结p=25.243125°Cd、L=5.6693cm、k=0.02、中点150°Cd、基温10°C，不在线重新拟合参数。

预测a+=GDD；有株高z到达时，以解析导数D=dh/da计算K=PD/(D²P+R)，更新a+=K(z−h(a))。协方差使用Joseph形式，保存预测、实测、更新、观测权重、方差及来源。

测量标准差5cm（R=25cm²）、过程方差4cm²/天、补值环境下过程方差乘4，均为工程假设。未按2025结果回调超参数。新观测只在到达后使用，历史已发布帧不回写。

## 环境风险

高温29°C、严重热34°C；低温14°C、严重冷8°C；高VPD2.0kPa、严重3.5kPa；低VPD0.3kPa均为工程阈值。一般热/冷/高VPD连续60分钟升为高风险，低VPD120分钟；高湿85%连续360分钟升为高湿环境提醒。阈值并非广辉201病害模型校准结果。

返回当前值、阈值、持续分钟、近24h暴露与检查建议；风险计时按数据时间。预警变化含触发、升级、解除，批量推进不丢弃事件。

102条高湿、226条热、99条冷、203条高VPD、138条低VPD、30条估计输入状态变化。这些数量包含解除和升级，不能当作独立灾害次数。没有输出百分比发病概率，预警不控制实物。

番茄叶霉病与高湿条件有关，环境提示依据[宾州州立大学推广资料](https://extension.psu.edu/managing-leaf-mold-in-high-tunnels)。湿度与叶面湿润对灰霉等病害的影响参考[UMass资料](https://www.umass.edu/agriculture-food-environment/greenhouse-floriculture/fact-sheets/botrytis-blight-of-greenhouse-crops)。缺少叶面湿润、病原、叶温观测，不据此判断已感染。

## 接口与使用

- POST /m3/live/start（year）：创建独立运行。
- POST /m3/live/{id}/step（expectedCursor、stepCount=1/12/48）：消费新增记录，返回新增帧/事件；重复游标拒绝推进。
- GET /m3/live/{id}：返回已消费记录，不返回未来观测。
- DELETE /m3/live/{id}：释放运行；最多8个，30分钟无活动后失效并在创建/访问时清理。

进入 `http://localhost:8100/#/modelCalibration`，点击“开始接入”，可暂停、单步、调速；“大棚实时展示”交接当前运行。页面刷新重新读取同一个URL运行并暂停，服务重启则提示重新开始。导出只包含已消费数据。

生产构建：Java8 `-Dmaven.test.skip=true`；Vue `dist-m3-live-20261002`。没有新增、编译或执行自动测试。已执行授权的顺序业务回放，并在浏览器从开始接入连续推进至2640/2640；查看了实时读取、预警、总干重、42次更新与完整曲线。随后经“大棚实时展示”打开同一运行，大棚面板保持2025-06-13 12:00、224.3cm、42次更新，再返回完整工作区。修复了URL绑定运行导致自动播放中断、Jackson总干重字段不一致的问题。
