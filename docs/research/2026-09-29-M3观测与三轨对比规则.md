# M3 观测与原始、修正模拟的对比规则

## 目标与状态

同一品种、季节、处理和环境输入下，对比M3实测、原模型、修正模型。M3文件尚未取得，本文件确定执行规则，不含虚构观测、不计算误差、不报告校准通过。

## 文件取得后的处理顺序

1. 将下载文件保存在E盘外部数据目录；核对发布方给出的文件大小与校验信息。保存本地SHA-256、来源记录、许可、下载时间。ZIP预览或网页元信息不等于已取得观测。
2. 只盘点归档中的资料文件；记录文件、工作表、原列名、行号、时间格式、品种、季节、处理、植株编号、单位，不执行压缩包内容。
3. 分别标记原始测量、提供方插值、项目转换或聚合数据；重复版本不作独立样本。
4. 以实际字段确认目标批次，默认候选为2025 / 广辉201 / CK。论文窗口参数不是已确认每株都有连续56天观测。
5. 单独存储观测与三轨运行结果，公共数据不得伪装为平台实时传感器或既有AgentRun历史。

## 统一观测契约

以下是内部目标字段，**不是声称M3文件已经具有这些列**；原列映射在取得文件后登记。

| 字段 | 要求 |
|---|---|
| dataset_version / cohort_id | 数据版本与季节、品种、处理组合 |
| plot_id / plant_id | 实际存在时保留；缺失则空，禁止编造编号 |
| observed_at / timezone | 带时区时间；保留原时间和解析方法，时区以资料说明为准 |
| metric / value / unit | 指标、有限数值、原单位；未知单位不得转成已确认单位 |
| basis | 单株、单位地面积、小区、采收累计、器官鲜/干重等分母与测量定义 |
| observation_kind | measured / provider_interpolated / derived |
| quality_flags | 缺测、重复、异常、未知单位、转换假设等；不静默删除 |
| source_file / sheet / row / original_column | 可回查原文件的位置 |
| transformation | 换算、聚合、插值方法及版本；原值另存 |

候选指标：温度°C、相对湿度%、CO₂ ppm、原始照度lux、株高cm、LAI m²/m²、器官干重、单株鲜果重或累计采收量。实际只启用单位和测量定义确认的指标。

## 环境驱动与时间对齐

- 温度、湿度、CO₂等M3观测若用于输入，则验证目标为株高、LAI或兼容口径的生长量。不能把环境输入回放正确称为环境模型预测准确。
- 固定30分钟网格并保存每个时段的有效测量数。如何聚合取决于原数据是瞬时值、区间均值还是区间累计；短缺不得偷偷线性补齐。长缺测段跳过或分段启动，并标明覆盖率。
- 用过去时段有效环境驱动作物模型；验证段不得用未来生长观测不断重置状态。初始状态与原模型、修正模型相同，记录建立方法和测量时间。
- 原始不规则生长观测保留真实测量时刻；匹配相应时刻模型状态，不把一条周测观测复制成多条日观测。
- 原始值和提供方插值可分别画曲线。主要误差只用原始测量；插值结果不增加独立测量样本量。

## 单位与分母

- lux、PPFD与W/m²分别保存。转换要有可追溯的光谱/换算依据及不确定性；不能把论文100 μmol/(m²·s)视作100lux。
- 株高按相同测量基点比较；单叶面积不直接等同LAI。
- 模型果实干物质不直接与实测鲜果质量比较。若缺少器官含水率或模型采收流，该指标暂记不可比较。
- 累计采收量与植株上当时存量不同；必须定义开始时刻、采收频次与完整生育期。
- 840株、252m²是全试验规模，不自动作为CK样本数和面积分母。单位地面积与单株转换必须使用该批真实密度与有效面积。
- 田间持水量百分比与体积含水率需要实测映射；没有依据时不得统一成一个百分比。

## 三轨与版本

| 轨迹 | 内容 | 必须保存 |
|---|---|---|
| M3观测 | 原始测量点，插值另标 | 来源、质量、测量定义、样本范围 |
| 原模型 | 当前参数在相同环境输入下的预测 | 代码版本、完整参数、初态、输入数据哈希 |
| 修正模型 | 校准段确定后冻结参数的预测 | 参数版本、训练范围、目标函数、优化方法、约束 |

参数证据清单仅指导候选选择；不能将文献增产比例直接用作校准系数。先解决测量与单位，再少量拟合能被数据辨识的参数，记录触及边界和多个参数相互补偿的情况。

## 保留验证与误差

- 优先以独立季节、处理或小区作为保留验证；数据不支持时使用按时间先后划分的完整日期段。时间边界应在查看校准结果前固定并保存。
- 保留段不参与参数选择、停止条件或单位换算系数调优。时间划分评价同一批未来外推；不能声称独立季节或新植株验证。
- 对每个指标、分组、数据段与模型版本分别计算误差；多株多时刻不能当独立重复，记录有效植株/小区数量。
- 令eᵢ=预测ᵢ−观测ᵢ：MAE=Σ|eᵢ|/n，RMSE=√(Σeᵢ²/n)，Bias=Σeᵢ/n。三者单位均与指标一致，Bias正表示高估。n仅计可比较的原始测量对。
- 无有效配对：指标为不可计算，n=0，不能填0误差。原模型RMSE=0时，不计算相对改进百分比。
- 改进率=100×(RMSE原−RMSE修正)/RMSE原，仅用于同一批相同保留配对点。允许负值，真实报告变差。
- 除总体误差，按时间查看偏差和残差，报告缺测覆盖率与异常记录数；未经保留验证时只能称已拟合。

## 后续实时数据

传感器接入沿用同一契约，来源标为真实采集，校时并保留质量标签。当前状态校正与长期参数校准分开记录；有足够观测和保留验证后才能发布新参数版本。

本轮成果是规则与接入准备。实际解析器、观测数据库和三轨展示应基于取得的真实字段继续实现。
