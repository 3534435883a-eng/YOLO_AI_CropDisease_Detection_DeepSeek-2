# 答辩问题与回答

**DuMate在作品里做了什么？**

DuMate接收自然语言研究需求，自主规划分析、策略对照和报告步骤，调用外部农业能力、读取返回值并解释权衡。既有DeepSeek解析器负责字段抽取，领域模型负责仿真。可执行Skill把这套流程变成可复用能力。

**哪些部分是这次新增？**

独立的三能力HTTP适配层、Bearer与参数/路径限制、结果状态映射、关联证据和调用键去重、可安装Skill及自包含客户端、范围明确的报告与交付材料。原有模型、知识库、UI及其他功能保留。

**为什么不用一个聊天回答完成？**

本任务需要可复算的模型指标及可追溯原文。工具提供实际计算结果，语言解释只能依据这些结果，不能自行补指标或实棚证明。

**是不是对用户棚况做了个性化仿真？**

不是。既有评测接口仅接收batchId/seed/days，当前是固定番茄参考参数和合成天气。农情草稿用于风险线索与人工核对，没有注入模型初始条件。必须保留该限制。

**P3是不是DuMate或LLM在决策？**

不是。P3在规则候选动作上进行短程前瞻仿真择优，不调用LLM。P3指标不能用来证明DuMate决策优于规则。DuMate的贡献在于组织整个研究任务、调用计算与交付解释。

**真实验证做到了哪一步？**

原后端437项测试通过；本层及独立客户端27项测试通过；独立客户端通过真实DeepSeek解析、P0–P6计算和报告链路，保存原始响应和摘要。它验证软件调用链和数据一致性，没有验证实棚产量、病害诊断或设备效能。DuMate界面加载、任务分享和录屏要用实际客户端证据确认。

**P3是不是最优？**

没有全面最优结论。当前P3比P2节水，但能耗和模拟亏损增加；病害积分下降，最终严重度增加。全部七组病害积分最低为P6，P3只在业务组P0–P3最低。不同指标需共同审阅。

**为什么产量多数为0、利润全部为负？**

这是当前模型假设、初始状态、成本规则和56天窗口下的实际输出，不能为了展示改动模型或数值。零产量和负利润提示该模型输出不能直接外推为真实经营收益，也说明需要检查参数、物候和观测支持。

**M3历史观测与本次评测有什么区别？**

原M3模块可顺序回放公开历史环境和生长观测。本次P0–P6评测的profile明确标识未校准模拟、合成天气及假设参数，不直接使用本次用户农情或M3回放曲线。两者不能混称实棚验证。

**如何避免重复提交和伪造报告？**

固定三条路径，客户端保存任务UUID和每步状态，适配层按调用键保存结果；失败和中断不自动换键重发。报告只读关联证据ID，指标来自真实矩阵。摘要用于变更核对，不是第三方认证或数字签名。

**云端评委能否直接运行？**

目前验收基于本机服务。Skill和代码可交付，云端节点不能访问本机127.0.0.1。远程运行需要管理员提供受控HTTPS适配地址、凭证和后端服务。平台分享页是否支持他人复跑必须实测，不把任务分享链接当成已部署的公网API。

**推广与商业价值是什么？**

现阶段适用于科研教学、实验记录与模型比较。可探索教学工具包和研究辅助服务，但没有付费客户、收入或生产提效的验证数据，不作商业成功承诺。
