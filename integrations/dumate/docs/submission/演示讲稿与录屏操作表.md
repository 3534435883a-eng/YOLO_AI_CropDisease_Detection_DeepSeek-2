# 四分钟演示讲稿与录屏操作表

这是录屏脚本，不是已经录制的DuMate视频。必须录制真实客户端执行，保留实际失败或等待，不以静态页面冒充现场调用。

## 演示前

1. 原农业服务9999运行；执行`integrations/dumate/scripts/start-adapter.ps1`检查/启动本层并验证鉴权。
2. 在DuMate安装并启用交付ZIP中的agri-research技能；检查Node >=22和环境配置。录屏时不要打开.env或secret界面。
3. 使用独立任务目录；不要覆盖旧证据或换键自动重发失败POST。
4. 系统/平台录屏工具的音频与画面应覆盖DuMate规划、三次调用和最终报告。

## 任务原文

> 我种植番茄，温室面积600平方米，目前坐果期，温度30℃，空气湿度88%，土壤含水率62%，下部叶片有少量黄斑，尚未确诊病害。请使用禾序农业研究技能，自主分析农情并在已有番茄参考场景中比较P0–P6，解释节水、能耗、病害风险和模拟收益的权衡。seed=20250419，模拟56天。只做研究与虚拟仿真，不操作真实设备。请交付带原文、批次和证据摘要的报告，以及人工复核事项。
