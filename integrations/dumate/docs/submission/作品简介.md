# 禾序农业研究助手

## 200字内简介

禾序农业研究助手面向农业科研与教学。DuMate理解自然语言需求，自主规划并调用农情解析、番茄策略仿真和报告工具，对比P0–P6的用水、能耗、病害压力及模拟收益，输出带原文依据、批次和证据摘要的实验说明。作品复用既有农业模型，以独立鉴权适配层和可执行Skill串联任务，明确区分用户陈述、历史回放与模型仿真，保留人工复核，帮助使用者理解策略权衡。

## 作品名称

禾序农业研究助手：DuMate驱动的可追溯虚拟策略对照

## 应用场景

教育科研 / 农业实验仿真 / 科研数据分析。农业生产人员可用于理解模型假设和策略取舍；不提供可直接执行的实棚处方。

## 技术贡献

既有农业系统提供DeepSeek字段抽取和确定性仿真模型。本次新增独立API适配层、可执行Skill客户端、任务证据关联、范围明确的策略比较和报告交付。DuMate负责自然语言理解、任务规划、按需调用与结果解释。P3仿真择优并不调用DuMate或LLM。
