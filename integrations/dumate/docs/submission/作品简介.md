# 禾序 Agent

## 200字内简介

禾序Agent面向农业科研与教学。DuMate理解研究目标，澄清比较基准、风险指标及允许增幅，调用农情解析与既有温室仿真工具，对P0–P3管理策略进行约束筛选和多指标排序，单列P4–P6消融结果。有合格且优于基准的方案则给出研究候选，无解则如实说明；输出原始结果、判定依据和可追溯报告。系统复用自主农业平台，所有设备响应及收益指标均为模型仿真，无实棚验证。

## 作品名称

禾序 Agent——基于 DuMate 的农业策略实验与智能决策辅助系统

## 应用场景

教育科研 / 农业实验仿真 / 科研数据分析。农业生产人员可用于理解模型假设和策略取舍；不提供可直接执行的实棚处方。

## 技术贡献

既有农业系统提供DeepSeek字段抽取和确定性仿真模型。本次新增独立API适配层、可执行Skill客户端、目标澄清与确定性筛选、任务证据关联及报告交付。DuMate负责自然语言理解、任务规划、按需调用与结果解释。P3仿真择优并不调用DuMate或LLM。自主开发及知识产权表述需由参赛团队按实际权属核对。
