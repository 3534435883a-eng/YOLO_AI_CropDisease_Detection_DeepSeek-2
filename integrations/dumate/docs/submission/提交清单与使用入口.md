# 交付清单与使用入口

## 已制作的材料

- 可执行`agri-research.zip`：SKILL.md、自包含Node客户端与报告生成器、执行说明，不含凭证。
- `禾序农业研究助手-应用方案.pdf`：正式方案，包含角色分工、技术架构、实际指标、软件验收及数据边界。
- 200字内作品简介、四分钟演示讲稿、录屏操作表、答辩问题与回答。
- 独立真实验收：客户端任务记录、三个原始响应、报告与比较范围文件。
- 完整适配模块源码包与release-manifest.json，可核对包的SHA256。

## 你在DuMate中的实际动作

1. 在同机保留农业服务9999；运行本模块`scripts/start-adapter.ps1`检查/启动9998并验证鉴权。
2. 按DuMate实际技能安装入口导入ZIP并启用agri-research，确保Node >=22。官方指南：https://cloud.baidu.com/doc/Dumate/s/5mmydgic3
3. 提交演示需求，让DuMate展示计划后逐步调用。Skill会自动读取现有本机.env；不要把密钥贴进对话。
4. 保存真实任务分享链接、完整执行录屏。发布前审阅标题、简介和公开文件，避免暴露配置和本机目录。
5. 将作品简介、方案PDF、真实分享链接和执行全过程材料提交至比赛系统。团队/指导老师等身份信息由用户填写，本文不编造。

## 尚不能由本机脚本证明的事项

Skill ZIP可执行验收不等于已经在DuMate客户端加载并启用；文件写入不等于平台注册完成。任务分享页、作品广场发布状态、是否允许评委复跑，需以实机界面和链接测试为准。正式录屏需拍摄真实DuMate运行，本轮不生成伪造的视频或链接。

Workflow/MCP为可选接法，比赛介绍鼓励可复用Skill，没有规定必须采用Workflow/MCP。保留本机HTTP执行方式的如实说明。参赛要求来源：https://www.saihuan.net/article/keji/299.html

## 发布审核范围

建议公开：简介、方案PDF、去除密钥和本机目录的录屏、Skill ZIP、经过审阅的实验报告。

不随作品公开：.env、私有状态目录、数据库、凭证、运行日志或用户实际生产资料。公开前先确认用户授权和文件范围。
