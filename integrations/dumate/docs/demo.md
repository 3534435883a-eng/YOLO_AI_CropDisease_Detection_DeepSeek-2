# 禾序农业研究助手：比赛演示素材

依据[用户提供的2026 iCAN比赛介绍](https://www.saihuan.net/article/keji/299.html)准备，截止日页面标注为2026-10-15。这里提供需求、叙事、简介和录屏脚本；并未生成或伪造DuMate平台分享链接和实机录屏。

## 作品简介（200字内）

禾序农业研究助手面向农业科研与教学，将农情描述、虚拟策略对照和实验说明串成可复用技能。DuMate自主规划并调用既有解析与P0–P6仿真接口，对比用水、能耗、病害压力及模拟收益，输出带批次与证据摘要的报告。系统区分用户陈述、历史观测回放和模型仿真，保留人工复核事项，帮助使用者理解策略权衡，避免把模拟结论当作实棚验证。

## 一次完整任务

直接向DuMate提交：

> 我种植番茄，温室面积600平方米，目前坐果期，温度30℃，空气湿度88%，土壤含水率62%，下部叶片有少量黄斑，尚未确诊病害。请自主调用农业研究工具，整理带原文依据的风险线索，再在已有番茄参考场景中比较P0–P6策略，重点解释节水、能耗、病害风险和收益之间的权衡。seed使用20250419，模拟56天。请提供可追溯报告和人工复核事项。只做虚拟仿真，不操作真实设备，也不把这个参考场景说成我的实棚实验。

用户描述是显式演示输入，不是实测数据。DuMate展示自己的规划，再连续调用三个能力。若工具失败，应展示失败与原因；不得把预存报告伪装为现场计算。

## 真实测试发现

本地HTTP E2E已经运行真实DeepSeek解析与原有仿真。7策略矩阵保存在[测试原始结果](evidence/e2e.json)；同键复用、另一键重新计算所得指标逐值一致。它证明本地API链路，不证明已在DuMate账号内执行。

实际参考场景结果有明显权衡：相对P2，P3模拟用水由66.36降至7.92m³，但能耗由3449.68升至5862.08kWh；模拟利润由-3553.5043变成-4051.6506元。病害压力积分下降，但最终模型严重度从50.7914增至77.1906。不能宣称“更节水所以全面更好”，也不能把负利润包装成盈利。

P0的零用水并不说明适宜生产，它同时没有模拟可售产量。所有数字来自当前模型假设与56天窗口，不对真实农户产量、病害或收益作承诺。
